type interactpolate_t

opaque handle for interpolation

void interactpolate_init_set_num_threads(int nthr)
[source]

Set the number of threads in generation of the interpolation points (default given by OpenMP). Not thread-safe, use single-threaded before calling interactpolate_abinit() if non-default value desired.

void interactpolate_init_set_num_points(int npts)
[source]

Set the number of points for interpolation (default: 2048). Not thread-safe, use single-threaded before calling interactpolate_abinit() if non-default value desired.

interactpolate_t *interactpolate_abinit(double U, double alpha, double eps, double gate_dist)
[source]

Initialize interpolation handle given Hubbard interaction \(U\), fine structure constant \(\alpha = 14.40\,\mathrm{eV}\text{Å}\), dielectric constant \(\epsilon\) (use \(\epsilon=1\) for vacuum) and gate distance \(\xi\). Returned handle must be freed with interactpolate_free().

interactpolate_t *interactpolate_init(double U, double ohno_dist, double gate_dist)
[source]

Initialize interpolation handle, deprecated version that uses Ohno distance, \(a\), Hubbard interaction \(U\), and gate distance \(\xi\). Can fail in some instances of badly chosen parameters. Use interactpolate_abinit() whenever possible!

double interactpolate_get(const interactpolate_t *ii, double r)
[source]

Get the value of the Coulomb interaction \(V(r)\) for a distance \(r\). Thread-safe (i.e. can be used inside a parallel region). Does not check for domain of \(r > 0\).

double interactpolate_get_safe(const interactpolate_t *ii, double r)
[source]

same as interactpolate_get() but with domain check (and correction) for \(r\)
